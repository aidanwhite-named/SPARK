# SPARK 특허 신규성·진보성 분석 도구

로컬 CLI를 사용해 `STEP1_인용발명선정.md`, `STEP2_구성요소대비.md`,
`STEP3_신규성진보성판단.md` 프롬프트를 순차 실행하는 웹 프로그램입니다.
API는 사용하지 않습니다.

## 실행

```powershell
python app.py
```

브라우저에서 `http://127.0.0.1:5050`을 엽니다.

## 기본 CLI 설정

기본값은 Gemini CLI입니다.

- 실행 파일: `gemini`
- 프롬프트 옵션: `-p`

긴 PDF 본문은 명령줄 인자가 아니라 표준입력으로 전달하므로 Windows 명령줄 길이
제한을 피합니다. 다른 CLI를 쓰려면 화면의 CLI 설정에서 실행 파일과 프롬프트
옵션을 바꾸면 됩니다.

## 결과 파일

분석이 완료되면 전체 결과가 `results/analysis_<작업ID>.md`에 저장됩니다.
